# Advantages of open source software

## Pros
Open-source software is software whose code is publicly available online. Anyone can read and change the code, unlike proprietary software, where only the original owner, or people who have been given permission, can change it. The term was coined in 1980 by Foresight Institute's co-founder Christine Peterson to attract new people to the project. Open-source software is published under a license that describes what a person can do with the code and what permission, if any, they are required to have. Some licenses are: Apache License 2.0, MIT license, GNU General Public License. Open-source software has plenty of advantages:
-**Transparency**. All the code is published online and can be read by every coder around the world. This means that whenever you start using the software, you know how it works and what it can do. Moreover, due to its openness, everyone can check and report bugs and vulnerabilities in the code. 
-**Control**. Programmers can change the code however they want and share their modifications with others online.
Safety. Due to the transparency, programmers can find bugs, issues, and vulnerabilities in the code and fix them or report them to the community in order to get them fixed. This can make fixing problems with open-source software faster than in proprietary ones.
-**Community**. Open-source software often has big communities that make it easier for beginners to join the project, learn, and start contributing. Moreover, the bigger the community is, the more the previous points are valid: more users mean more eyes checking the code, which makes it easier to find problems and, when found, faster to fix them.
